MySQL ⇄ BigQuery Converter

Drop in a ZIP, get the other format back as a ZIP. Everything runs in your browser — nothing is uploaded.

Drop a ZIP here, or click to choose BigQuery: ZIP of .csv files  ·  MySQL: ZIP containing a .sql dump
  • BigQuery → MySQL: one CSV per table (header row required). Column types and the primary key (first *_id column, if unique) are inferred from the data. Output is one .sql file with DROP/CREATE/INSERT.
  • MySQL → BigQuery: reads CREATE TABLE and INSERT statements (mysqldump works). Output is one CSV per table plus schema/<table>.json for bq load --schema.
  • Foreign keys can't be inferred from CSVs, so they are not generated.
