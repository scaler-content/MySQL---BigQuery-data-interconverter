MySQL ⇄ BigQuery Converter

Drop in a ZIP, get the other format back as a ZIP. Everything runs in your browser — nothing is uploaded.

Drop a ZIP here, or click to choose ZIP of .csv files (BigQuery or MySQL style)  ·  or a MySQL .sql dump
  • BigQuery → MySQL (CSV): empty cells become NULL and UTC is dropped from timestamps. Every other value, including booleans (TRUE/FALSE, T/F, Y/N, Yes/No, 1/0), is copied exactly as it is.
  • MySQL → BigQuery (CSV): NULL and \N become empty cells. All other values are copied exactly as they are.
  • A ZIP with a MySQL .sql dump also works (output: CSVs + schema/<table>.json).
  • Auto-detect looks for NULL cells (MySQL) or TRUE/FALSE (BigQuery); if unclear, choose the direction manually.
